# antoniocosta.co.uk

Personal profile page of Antonio Costa, Senior .NET Backend Engineer in Stirling, Scotland.

Static HTML and CSS, no build step, served by GitHub Pages. The page is styled as an editor window and prints to a single A4 sheet.

- `index.html`, `styles.css` — the page
- `assets/` — photo, fonts (self-hosted, Google Fonts via Fontsource), QR code, social preview image
- `cv/` — the current CV as PDF
